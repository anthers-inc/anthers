# Glossary

---

Key terms and concepts used throughout the Bluebell platform and documentation.

## Platform Terms

| Term | Definition |
|------|-----------|
| **AT Protocol** | The decentralized networking protocol (used by Bluesky) that Bluebell is built on, enabling portable identity and federation. |
| **Creator** | A user who publishes content on Bluebell -- games, posts, video, or audio. |
| **Creator Hub** | A creator's personalized profile page showcasing their projects and posts. |
| **Federation** | The ability for multiple independent servers to interoperate, allowing users to maintain their identity across platforms. |
| **Project** | A content listing on Bluebell, typically a game but applicable to other downloadable media. |
| **Post** | A creator update that can contain rich text, video, or audio content. |

## Financial Terms

| Term | Definition |
|------|-----------|
| **Community Resilience Fund (CRF)** | A 3% contribution from transactions that funds shared infrastructure, free-tier hosting, and community reserves. |
| **Creator Pool** | A pool of subscriber contributions distributed proportionally to creators based on user attention time (play, watch, read, listen). |
| **Boost Pool** | Additional subscriber funds allocated to specific creators, which gates access to premium content. |
| **Transparent Pass-Through** | Bluebell's pricing model where infrastructure costs are shown line-by-line rather than hidden in a percentage cut. |
| **Pay-What-You-Want (PWYW)** | A pricing model where users choose how much to pay, with an optional minimum price. |
| **Stripe Connect** | The payment infrastructure that enables direct creator payouts. |

## Technical Terms

| Term | Definition |
|------|-----------|
| **HLS** | HTTP Live Streaming -- the adaptive streaming protocol used for video and audio playback. |
| **Transcoding** | The process of converting uploaded media into optimized streaming formats. |
| **Slug** | A URL-friendly identifier for a project (e.g., `my-cool-game`). |
| **Game Jam** | A community event where creators build games around a theme within a set timeframe. |
