# Bluebell Wiki

---

This wiki contains guides and documentation for users and creators on Bluebell, a federated, creator-first media platform.

## Areas

| Range | Area | Audience |
|-------|------|----------|
| 10-19 | General | Everyone |
| 20-29 | Users | Subscribers, players, content consumers |
| 30-39 | Creators | Content creators, publishers |

## How to Use This Wiki

Browse by area using the sidebar, or use the search bar on the wiki home page to find specific topics. Each section starts with an overview page (README) that introduces the topic and links to detailed sub-pages.
